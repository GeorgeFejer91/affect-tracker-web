Current boundary

  • This slice implements a fresh 192-bit QR bearer secret and BRSP/1 observe/control scopes only.
  • OPAQUE password-file login, passwordless local approval, public beacon discovery, reconnect, and record export are not implemented here.
  • VDO.Ninja uses Internet signaling, STUN, and possibly TURN. Direct peers may expose network addresses; a relay may add latency.
  • The pinned VDO transport is loaded only after Connect, in the same browser realm as the controller, and is trusted not to inspect controller memory.
  • The BRSP proof and scope gate currently run in the bundled desktop WebView. Rust still validates the typed study action through its native authority. This is not the final security architecture.
  • No public VDO route, physical phone, forced-TURN, or packaged desktop platform has been qualified for this slice.
