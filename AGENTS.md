# Affect Tracker agent entrypoint

Before inspecting, planning, editing, testing, or publishing this repository, every AI agent MUST read all Markdown files in [`for-ai/`](./for-ai/) in lexical order.

The documents in `for-ai/` are the durable product contract. If implementation and documentation disagree, stop, identify the mismatch, and update the implementation or propose a deliberate contract change. Do not silently weaken web/desktop parity, privacy, accessibility, LSL semantics, or the supported-platform matrix.

After reading `for-ai/`, follow any more-specific `AGENTS.md` in the subtree being changed.
